# Contribuir

1. **Todo cambio deja `npm test` en verde** y toda funcionalidad nueva suma su caso E2E en `dev/entorno.js` (corre contra un MercadoLibre simulado, sin cuenta real).
2. **Desarrollo**: `npm install` → `npm test` · `npm run dev` (ML simulado en :9990, conectar con code `CODE-OK`).
3. **Cero secretos** en el código, ni siquiera en pruebas.
4. **Textos al usuario en castellano**.
5. Escrituras siempre con confirmación del usuario y respetando `ML_SOLO_LECTURA=1`.
6. Un PR = una funcionalidad.
